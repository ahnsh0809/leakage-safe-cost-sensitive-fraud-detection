# Leakage-Safe and Cost-Sensitive Fraud Detection with Temporal Validation

## Overview

This project develops a fraud detection pipeline designed to avoid temporal data leakage and evaluate models under realistic future-data conditions.

The project focuses on:

- chronological validation
- past-only behavioral features
- class imbalance
- probability calibration
- transaction-level proxy costs
- cost-sensitive decision thresholds
- capacity-constrained fraud alerts

## Datasets

### Sparkov
Used as the main development dataset for temporal fraud detection experiments.

### ULB European Credit Card Fraud Dataset
Used as an external validation dataset based on anonymized real credit card transactions.
